Resona это неофициальный клиент SoundCloud с открытым исходным кодом. Без рекламы, без сбора данных.

- Скачивание для офлайна без подписки
- Тексты песен почти для чего угодно, даже для нишевых треков, несколько источников по цепочке как запасной вариант, и синхронный таймкод там, где он есть
- Домашний микс, который постоянно подкидывает новое от артистов, которых вы уже слушаете
- Импорт треков прямо из чатов Telegram
- Слежение за папкой, которое само подхватывает локальные файлы
- Избранное и плейлисты, с мультивыбором и свайпами
- Статистика прослушивания
- Свои цветовые темы, иконки приложения, динамический цвет от обложки трека
- Регистрация не нужна, войти можно, если хотите синхронизировать свои лайки

Не связано с SoundCloud. Лицензия GPLv3.
